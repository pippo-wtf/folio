Folio for Mac

1. Open Install Folio in the disk image.
2. Choose Install Folio. It uses your personal ~/Applications folder.
   Quit an existing Folio before installing; your documents and settings stay.
3. Folio opens and asks whether it should be your default Markdown app.
   Choose Make Default or Not Now. You can revisit this in the Folio menu.

No administrator password is needed. The shared /Applications folder is not used.

Requires an Apple silicon Mac with macOS 14 or later.

For a signed release with in-app updates, Folio checks for availability and
shows release notes. It downloads and installs only after you choose Update.
You can also choose Check for Updates in the Folio menu. If this is a local
development preview, use a newer installer to replace it manually.

Your documents, recovery copies, highlights, and saved preferences are
separate from the app and remain when replacing it.
