# Folio 0.14.1 — Every column in view

Tables can now extend up to 25% beyond the reading column. Long text, links and inline code wrap inside their cells, so you can read every column without scrolling sideways. Paragraphs and other content keep their existing width.

Works in Read and Write modes, including narrow windows and enlarged text.

Updates install only when you choose Update.
