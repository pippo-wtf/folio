# A quieter page. A better place to write.

- One pencil switches between focused reading and writing on the page.
- Text keeps the same typography, spacing and line wrapping in both modes.
- Edit simple tables, code and local images from their pencil controls.
- Save highlights, add comments and return to marked passages.
- Safer saving, local draft recovery and better preservation of literal text.
- Updates show release notes and install only when you choose.
- Apple-notarized installation into your personal Applications folder, with an optional default Markdown reader prompt.

Apple silicon · macOS 14 or later · Free and open source.
