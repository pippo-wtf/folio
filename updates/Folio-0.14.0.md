# Folio 0.14.0 — Read together. Reply to your agent.

- Shared Markdown review in the regular Folio app: highlights, comments, replies and completed tasks.
- A short first-launch name setup, with completion labels such as “Done by Philip”.
- Shared-folder watching and protected saves with conflict recovery.
- Comments beside the text, roomier inputs and a Copy content button.
- Fixed task checkboxes getting stuck after being unchecked.
- Safer saving and agent feedback for accented text, plus improved narrow-window reading and sidebar scrolling.

Choose an already shared OneDrive folder to begin. Changes sync through OneDrive; this is not live co-editing. Full two-Mac recovery acceptance is still pending.
