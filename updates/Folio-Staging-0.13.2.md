# Folio 0.13.2 — A warmer after-dark read

Green Line now feels at home after dark: charcoal pages, warm text and a soft orange accent. The familiar white-and-green light appearance stays just as it is.

- Choose Light, Dark or System in the appearance menu.
- Your fonts, spacing and document stay the same when you switch.
- Highlights, links and writing controls follow the appearance; saved highlights remain 50% transparent.
- Dark code blocks and the sidebar use coordinated, quieter colors.

Updates still wait for you: review the notes, then choose Update Folio. Nothing installs automatically.

Staging also keeps the layout controls, including separate light and dark accent colors.
