# Shared review
1. Open Folio and enter your name once.
2. Choose **File → Add shared folder…** and select an already shared OneDrive folder.
3. One person creates the workspace; others join after OneDrive syncs it.
4. Share a Markdown document from the folder. Select text for shared highlights and comments, or check tasks to show who completed them.
5. Enable **Allow changes to shared Markdown files** to save text and task changes into the original file.

Private marks stay private. Everyone needs access to the same folder; Folio does not invite people or change OneDrive permissions. Display names identify contributions without verifying identity. OneDrive delivers saved changes, not live cursors.

Folio keeps recovery copies and asks you to resolve conflicting edits. Up to eight documents per workspace are currently supported. Local multi-participant and installed-app checks have passed; full two-Mac OneDrive recovery acceptance remains pending.
